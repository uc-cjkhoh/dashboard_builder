# Backlog: charts, authoring and formatting

Chart, authoring and formatting work not yet built. Format: [index.md](index.md#how-to-read-an-entry). Built chart types are in [worksheet-charts.md](../../concepts/worksheet/worksheet-charts.md).

## Chart gaps

- **Continuous time axis, gap filling and true jump lines** (IDs: T03-05 remainder, T03-07; priority P1) — Open: a true jump line (disconnected horizontal segments with no risers, as in Tableau; the current Step (centred) is a connected step); lines sit on a category axis, so unevenly spaced dates are drawn evenly and missing periods are not filled. Partial: discrete and truncated date parts exist; no continuous time axis or gap filling. Needs: none.
- **Layered marks and dual axis beyond line, area and the combo** (IDs: T03-16 remainder, T03-17 remainder; priority P2) — Partial: the combo and Line / Area (Format → Dual axis) put measures on a right axis with Synchronise axes. Open: a dual axis on scatter; independent mark types per measure (all right-axis measures share one type, and line / area have no right-axis mark choice); a user-set axis range or a synchronise that spans a field the chart does not plot. Needs: none.
- **Density mark and Gantt remainders** (IDs: T03-14 remainder; priority P2) — Partial: Gantt draws one bar per member from a start measure and a length or end measure (Format → Length), splits by a categorical Colour field into a bar per row and member, and a bar click selects its row ([D104](../../decisions/decisions-dashboards.md#d104--a-gantt-takes-its-end-from-a-field-splits-by-colour-and-is-a-click-target)). Open: no density surface (a smoothed 2-D point cloud); dependencies (arrows between bars need a link field and a drawn path per pair); a numeric field on Gantt Colour (a gradient); a Gantt end read from a date part or a text date format the server does not return as `YYYY-MM-DD`; a NULL colour member and a member literally named "—" share one legend entry and colour (as on the other categorical charts). Needs: none.
- **Palette editing and member-colour gaps** (IDs: T01-20 and T03-24 remainder, T03-33 remainder; priority P2) — Partial: diverging continuous colour (a centre value) is built for heatmap and scatter with a chosen hue pair (Orange / Blue, Amber / Violet, Green / Violet, from tokens, [D85](../../decisions/decisions-dashboards.md#d85--the-diverging-scale-picks-its-hues-from-tokens-not-a-free-hex-picker)). Open: custom palette editing and a free-hex picker (only 24 fixed swatches; needs a stored-colour contrast and saturation rule first); member colours cannot be set from the legend (a legend click highlights), cannot be assigned to treemap or funnel members, and are unsupported for calculated fields; no reversed-per-field ramps; the table's diverging scale keeps the Orange / Blue pair. Needs: none.
- **Marker and border refinements** (IDs: T01-22 remainder, T03-34 remainder; priority P2) — Partial: Format has a marker size (4–40 px), a marker shape on line charts, and a none / thin / medium / thick mark border with a colour from four palette tokens (muted, ink, surface, accent) for scatter, line markers, circle heatmap, bars, cells, pie, treemap, funnel, histogram, box plot, waterfall, bullet, Gantt and Sankey (gauge has no marks). Open: a free border colour or arbitrary width (needs the stored-colour contrast rule in the palette-editing entry); per-series marker size and shape. Needs: none.
- **Marks parity with Tableau** (IDs: T03-19 / T03-20 / T03-21 remainder; priority P2) — checked against Tableau's Marks-card help on 2026-11-10. Open: a colour measure on several measures, Stacked or Combo (Tableau colours every mark by it; here one measure only, else a hint); Size on pie / donut (a hint today: Tableau sizes a pie per member of a Rows / Columns dimension, which needs a panelled pie — a second dimension, one pie each, radius following the Size measure, capped like small multiples, [D108](../../decisions/decisions-dashboards.md#d108--size-a-dimension-steps-marks-edit-sizes-a-lines-own-thickness-text-size-and-size-beside-a-colour-split)); a measure on Shape (binned) and choosing a shape per member; the continuous colour default (Tableau starts Diverging when the data crosses zero; here Low → high) and Use Full Color Range; mark opacity; several fields on Colour; Label options (min / max, line ends, most recent); a Colour dimension on pie / donut beyond the slice field. Needs: none.
- **Measure-filter remainders and a range slider** (IDs: T03-27 remainder; priority P2) — Partial: a measure pill carries a number condition on its aggregated value (SQL `HAVING`, [D84](../../decisions/decisions-filters.md#d84--a-filter-on-an-aggregated-measure-having-keeps-groups-after-grouping)). Built too: a range slider for `between` ([D87](../../decisions/decisions-filters.md#d87--the-measure-filter-range-slider-reads-its-span-from-the-drawn-result)). Open: a filter on a measure that isn't on the view, on a Top-N ranking measure, or on a Size / Colour / Label measure; a filter shared across dashboards; the Other bucket together with a measure filter; histogram and box plot. Needs: none.
