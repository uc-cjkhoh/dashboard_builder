# Backlog: calculations and table calculations

Calculation work not yet built. Entries are in dependency order. Format: [index.md](index.md#how-to-read-an-entry).

Built behaviour (functions, parameters, statistics on plain measures): [calculated-fields.md](../../concepts/worksheet/calculated-fields.md).

Rules for new work:

- Every new function goes through the whitelisted expression tree, never formula text on the server.
- LOD (level of detail) terms and any new function whitelist entry keep the endpoint's limits and response shape. The endpoint never accepts SQL text.

- **Logic functions remainder** — Built: a date literal `#2024-01-31#`, `IN` over date literals and a boolean compared with `=` / `!=` ([D101](../../decisions/decisions-logic.md#d101--a-date-literal-is-hash-delimited-in-over-dates-and-a-boolean-compares-with--and-)). Open: an `IN` list read from a field or another source (a read-only sub-select of a catalog-validated column, bounded by a `LIMIT` and its own time limit; needs an owner decision on how a subquery fits "never accepts SQL text" before it is built, and a caching rule), and a date `[@Parameter]` as a date literal or `IN` value (it becomes `DATE(text)`, which is not a list value). Needs: none.
- **Text functions remainder** — Built: regular expressions (`REGEXP_MATCH`, `REGEXP_EXTRACT`, `REGEXP_EXTRACT_NTH`, `REGEXP_REPLACE`; [D107](../../decisions/decisions-logic.md#d107--regular-expressions-four-functions-a-literal-pattern-re2)). Open: a pattern or replacement that is a field (ClickHouse needs a constant pattern), look-around and back-references (RE2 has none), case-insensitive flags beyond a leading `(?i)`, and a `LEFT` / `RIGHT` / `MID` length or `SPLIT` position or separator that is a field or computed value (a `[@Parameter]` works). Needs: none.
- **Date functions remainder** — Built: `FISCALYEAR` / `FISCALQUARTER` with a literal start month ([D93](../../decisions/decisions-logic.md#d93--fiscalyear-and-fiscalquarter-take-a-literal-start-month)); `DATENAME` parts `'year'` and `'quarter'` (as text). Open: `TODAY()` / `NOW()` (non-deterministic; need an owner decision, [D60](../../decisions/decisions-calculation-functions.md#d60--no-today--now)), a fiscal year start as a workbook or per-field setting (date-part bucketing a plain date by fiscal year), fiscal week and fiscal month, date-part bucketing of a calculated date (a calculated date dimension groups per distinct value; `DATETRUNC` is the workaround), `DATEPARSE` with a format, time zones, a unit, amount or part that is a field (a `[@Parameter]` works). Needs: none.
- **Parameters remainder** (IDs: T04-31, T04-32; priority P2) — Built: a Constant reference line, a typed band's two ends, the forecast steps (whole 0–24) and the moving-average window (whole 2–30) follow a number parameter. Open: a step size exists only for a number range (not for "any value"); a calculated field reads a parameter only through `[@Name]` (no parameter picker in the pill menu). Needs: none.
- **Filters on calculated fields remainder** — Built: a row-level calculation as a Filters field ([D82](../../decisions/decisions-filters.md#d82--a-calculated-field-is-a-row-filter-applied-before-grouping)); the box plot applies it, and the histogram and View data apply one that reads their table alone ([D91](../../decisions/decisions-filters.md#d91--a-calculated-filter-on-a-single-table-read-reads-that-table-only)). Open: an aggregate calculation as a filter (`HAVING`; waits for level of detail), a calculated filter shared across dashboards, `in the` (relative date) and Top-N on a calculation, a calculated Pages field, drill level or date-range field; the histogram (a calculated *field* on its shelves) and a calculated filter that reads a second table are not supported by the single-table histogram and View data; click-to-filter is off when the primary dimension is a calculation. Needs: none.
