# Components — CSS class vocabulary

The builder's surfaces and the classes that style them. Look up a class here before adding a new one.
Shared components live in `Features/Core/core.css`; feature-specific ones in
`Features/<Feature>/<feature>.css`. There are no report lists or record-CRUD tables here; this is an
explorer, not an admin template.

| Icon actions | `.iconbtn`, `.iconbtn--danger` (remove entity, close tab, disconnect); a card's ✕ rests muted and turns danger on hover / focus (D140). Every icon button on the Data Source tab has no hover box — no fill, no outline: the glyph steps from its muted rest ink to a colour set by the button's purpose (`--ib-hover` in `buttons.css`): `--ink` to move on or put away (close, previous / next, collapse caret, sidebar collapse); `--accent-ink` for the product's own action (the ☰ menu, inspect — Profile, peek, preview — edit connection, refresh / re-run, export); `--ok-ink` to add (a table chip's add; it already rests green once placed, so its hover does not change); `--warn-ink` to end something recoverable (Disconnect); `--danger-ink` to remove (a card's ✕, a key pair's remove, a recent connection's remove). The hue is a second cue — icon and title carry the meaning (rule 9) — and red stays danger alone. Pressed scales to .96. Scope: the cards, the sidebar's brand / connection / table list, the data preview, the relationship, rows and column-profile dialogs (`buttons.css`, "Data Source icon buttons"; the same scope is excluded from the lift rules above it). ## Drag surfaces are not click targets

- A `.table-chip` exists to be **dragged** onto the canvas; its `＋` button is the non-drag fallback.
  It is not a link.
- An `.entity` is **moved by dragging its head**. It exposes explicit affordances only: icon buttons in the head
  (the ☰ actions menu, collapse caret, remove), a Needs a partner label, the top and bottom resize strips and drag handles on the rows. The card body performs no hidden action, so nothing about
  it should promise one.
- Grid rows get a plain hover; they are not clickable.
